# BunnyOS / 萝卜机

支持多设备访问的个人 AI 聊天桌面。

完整应用需要运行 Node.js / Express 服务。这个 GitHub Pages 页面提供项目说明；聊天、存储和推送由应用服务处理。

## 启动应用

安装 Node.js 18 或更新版本，下载或克隆仓库后，在项目目录运行：

```sh
npm install
npm start
```

然后访问 <http://localhost:3000/index.html>。

Windows 也可以双击 `start.bat`，macOS / Linux 可以运行 `./start.sh`。
