# BunnyOS / 萝卜机

支持多设备访问的个人 AI 聊天桌面。

[直接打开网页版](https://gdog0622.github.io/bunnyos/)即可使用，存档保存在你自己的浏览器中，也可以手动备份到个人云存储。需要服务器存储、后台推送或本机 MCP 时，可以使用下面的自部署方式。

## 启动应用

安装 Node.js 18 或更新版本，下载或克隆仓库后，在项目目录运行：

```sh
npm install
npm start
```

然后访问 <http://localhost:3000/index.html>。

Windows 也可以双击 `start.bat`，macOS / Linux 可以运行 `./start.sh`。
