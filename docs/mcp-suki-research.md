调研日期：2026-10-24。用途是为 BunnyOS 选择合适的产品流程；本次实现为原生 HTML/CSS/JavaScript 与 Express 模块，没有搬入参考项目的业务代码。

## 常见设计与本次选择

### 工具：连接 → 发现 → 调用 → 确认 → 结果

1. 用户为服务填写地址或启动命令，以及所需的认证配置。
2. 测试连接，发现服务支持的工具和参数，明确是否启用。
3. 模型按需调用；工具结果回传模型，模型继续回答。
4. 有外部影响的操作先展示真实参数，用户确认后提交。
5. 保留操作状态和执行结果；失败、拒绝、过期与结果未知分别显示。

本次增加桌面「工具」App，也能从设置进入。聊天工具默认关闭，避免旧模型不支持 function calling 时影响既有聊天。内置当前时间、提醒创建/查询/取消；联网搜索需要 Tavily Key 或搜索 MCP。所有启用工具共用当前主 API。

MCP 使用[官方 TypeScript SDK 的 v1 维护线](https://github.com/modelcontextprotocol/typescript-sdk/tree/v1.x)，保持项目的 Node 18+ 兼容性，支持 stdio、Streamable HTTP 与旧版 SSE。没有引入新的前端框架。协议依据见 [MCP 2025-11-25 Transports](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)。

默认所有外部 MCP 调用都需确认。用户可以单独允许某个服务自动执行它声明为只读、且未声明为破坏性的工具；这是对该服务声明的信任选择。其余调用均保留确认流程。确认有效期为 15 分钟，参数不可在确认请求中替换，服务配置改变后旧确认不可执行。自动动作也会记录结果。

点单的实际商家、配送、地址、登录和支付取决于接入的 MCP；BunnyOS 本身没有外卖平台账号，也没有伪造“已下单”的接口。现有 QQ 角色扮演的外卖/礼物卡片仍独立存在，真实工具卡片显示服务名、调用参数和服务返回结果。

### 情侣空间：共同首页 → 日常互动 → 长期记录

用户已确认使用「我 + AI 角色」模式。每个角色建立独立空间，不新增真人配对、邀请码或另一套账号系统。

- **小家**：双方名字和头像、相恋天数、当日心情、下个纪念日、每日问答、共同小兔。
- **日记**：保存文字和照片，按时间回看；可以邀请当前角色留下回应。
- **纪念日**：名称、日期、每年重复、倒计时；闰日按非闰年 2 月 28 日计算。
- **心愿**：添加共同事项、勾选完成、显示进度。
- **AI 联动**：问答和日记回应复用现有角色、主 API 和预设；近期空间记录进入 QQ 上下文，角色能知道你们留下的内容。

视觉采用暖白、淡粉、卡片和底部导航，适配现有桌面 iframe 与窄屏。小兔使用项目原生 SVG，照顾记录每天最多累计一次；这是首版共同养成，没有装扮商城或 3D 家具系统。AI 回应按点击生成，未声称角色离线自主活动。

## 使用

### 先启动

更新依赖后重新启动服务：

```sh
npm install
npm start
```

刷新 BunnyOS 桌面，出现「工具」和可打开的「Suki」。若已在运行旧进程，需要先停掉旧进程；只刷新网页不会更新后端。

### 在聊天中搜索、提醒

1. 在「设置 → 通用 API」配置支持 `tools / tool_calls` 的 Chat Completions 兼容模型。
2. 打开「工具」，开启「在 QQ 聊天中使用工具」。
3. 联网搜索可直接保存 Tavily API Key；API 定义见 [Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。也可添加搜索 MCP。
4. 返回 QQ，说“十分钟后提醒我喝水”“帮我查一下……”。提醒时间有歧义时，角色应先询问。
5. 在「工具 → 提醒」管理提醒；需要系统通知时开启本设备推送。

提醒按带时区的绝对时间存储。提醒页输入使用当前设备时区。服务每秒检查到期项，先写触发状态，再发前台事件和现有 Web Push；停机时不会响，重启后补发。浏览器或系统限制可能延迟/阻止通知，因此它是网页提醒，不是手机系统原生闹钟。

### 添加 MCP

远程 Tavily 示例：

- 方式：Streamable HTTP
- 地址：`https://mcp.tavily.com/mcp/`
- 请求头：`{"Authorization":"Bearer 你的 Tavily Key"}`
- 保存后点「测试连接」，成功时列出发现的工具。

本机服务填 `stdio`、可执行命令、JSON 参数数组和 JSON 环境变量字典。命令在 **BunnyOS 后端所在机器**执行；手机访问 VPS 时，它运行在 VPS。SDK 只继承运行所需的默认环境及显式配置，未把 BunnyOS 登录密码等环境变量整体传给子进程。不要把密钥写进命令参数或 URL，优先放在环境变量或请求头。

当前支持静态 Header/API Key 认证，尚无内置 OAuth 登录向导。若服务仅提供 OAuth，需要先取得可用令牌，或使用该服务支持的本地连接方式。

### 建立小家

打开 Suki，选择 QQ 中已有的角色，填写小家名称、你的名字、相恋日期和时区。以后从 QQ 对话头部的爱心按钮，也能进入这个角色的小家。

每日问答先保存自己的回答，再点“听听 TA 的回答”。日记先保存，再邀请角色留言。AI 调用失败不会删除已保存的记录。纪念日显示倒计时；需要到点提醒时单独在工具页建立提醒。

## 数据与边界

| 数据 | 独立存储目录中的位置 | 云备份 |
| --- | --- | --- |
| 角色空间 | `data/suki/<characterId>.json` | 包含 |
| 日记照片 | `data/assets/chat-images/` | 包含 |
| 提醒 | `data/reminders.json` | 包含 |
| MCP 命令、环境变量、请求头和搜索密钥 | `data/tools/config.json` | 不包含，保留当前机器的配置 |
| 工具调用和确认回执 | `data/tools/actions.json` | 不包含，保留当前机器的回执 |

设置和空间修改使用版本校验；另一台设备先保存时返回 409，保留本地输入并提示重新加载。异步 AI 回应提交前再次检查版本。配置、提醒、回执和空间均原子写入 JSON，沿用现有单进程部署要求。

执行前先保存 `running` 回执，执行后保存结果；重复确认同一条回执不会重新执行。网络中断或进程退出可能使远端已经执行、而本机尚未取得结果，这时保留记录并要求核对服务方，不能承诺外部系统的 exactly-once。备份恢复也不会复活本机旧的 MCP 确认。

## 验证

`tests/tools-suki.test.js` 使用本地模型和 MCP 测试服务，覆盖模型工具循环、HTTP 的 JSON/SSE 响应、stdio 环境隔离、确认/拒绝/过期、重复确认与重启、提醒触发、角色隔离、版本冲突、日记照片、AI 回应与备份。测试服务不提交真实订单，也不调用付费搜索。

本次没有可用的浏览器自动化通道，未完成真实浏览器的视觉验收；没有使用个人密钥或真实商家账号测试搜索、下单、支付及系统推送到达情况。
